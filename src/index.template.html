使い方と注意事項

基本操作

  1. JSONL / NDJSONファイルを選択またはドロップします。
  2. 解析が終わると、正常行・確認が必要な行・フィールド構成を確認できます。
  3. Table / Recordを切り替え、ページ単位で内容を確認します。問題行をクリックすると該当ページへ移動します。
  4. 現在ページをJSONLとしてコピー、またはCSVとしてコピー・保存できます。

プライバシー

読み込んだファイルはブラウザー内だけで解析します。このアプリから外部サーバーへ送信しません。

注意事項

  • JSON LinesはUTF-8を前提として解析します。
  • 閲覧専用です。元のファイルを書き換えません。
  • 問題のある行があっても、正常な行は引き続き確認できます。
  • フィールド集計はトップレベルのオブジェクトを対象にします。配列やプリミティブは __value として扱います。
  • CSV出力はファイル全体ではなく、現在表示しているページが対象です。
  • JSONLコピーは現在ページの正常な行だけを対象にします。
  • gzip圧縮された .jsonl.gz / .ndjson.gz は現在のバージョンでは直接読み込みません。

配布用HTMLは実行時の外部通信を必要とせず、ローカルファイルとして直接開けます。
